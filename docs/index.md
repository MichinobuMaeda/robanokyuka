# ![ロバの休暇](logo.svg)

<https://robanokyuka.firebaseapp.com>

![https://robanokyuka.firebaseapp.com>](qrcode.png)

ロバの休暇は休暇取得の計画と記録のための無料のアプリです。[利用規約](./info.md)をご確認の上、ご利用ください。

通常は職場の方でも有給休暇の記録はされていて、自分の勤怠をシステムで確認することができる人も多いでしょう。でも、仕事をしていないときに、プライベートの予定のことを考えながら有給休暇を決めたいことがあります。また、このアプリの作者の職場のようにセキュリティ上の理由でプライベートの予定が入った自分のスマホを持ち込めないところもあります。そのため、作者はExcelを使って自分の有給休暇を管理していたのですけれど、スマホでの使い勝手が良くないためアプリにしました。
